# Abus Apartment

The Abus Apartment website is a React app built with Vite.

## Run locally

```sh
npm ci
npm run dev
```

## Deploy to GitHub Pages

The GitHub Actions workflow builds and deploys the site when changes are pushed
to `main` or `master`. In the repository settings, set **Pages → Build and
deployment → Source** to **GitHub Actions**.

Once deployed, the site is available at
https://joxxef-dev.github.io/abus-apartments/.

Routes use hash-based URLs so pages also load directly and on refresh on GitHub
Pages.
